# 海南海商智谷 · 3D 交互园区

海南海商智谷产业园，中小企业创新创业孵化基地。

**网站访问：** [https://supera7.github.io/haishang-zhigu-3d/](https://supera7.github.io/haishang-zhigu-3d/)

## 体验

- 参考园区实景照片搭建的 3D 建筑，支持旋转、缩放、日夜氛围。
- 靠近建筑 → 穿过入口 → 走进空间，分层渐进的镜头体验。
- 第三步展示园区原始视频提取的实景照片，保留真实空间画面。
- 开放办公、独立办公、共享会议、会客交流、阅读空间、前台服务、门卫停车和园区食堂，八大空间自由切换。
- 支持查看照片细节及播放原始视频片段。

## 源代码

[下载完整、可独立运行的源代码 source.zip](./source.zip)。解压后进入 haishang-zhigu-3d 目录，在 Node.js 22.13 或更新版本中运行：

```sh
npm ci
npm run dev
```

执行 `npm run build` 生成 `dist`，其内容可直接部署到静态服务器。源代码包含 React / TypeScript / Three.js 组件、Vite 配置、依赖锁定文件、全部实景素材与运行说明。

## 发布方式

本仓库根目录是已经构建好的静态站点，由 GitHub Pages 从 main 分支根目录发布。`.nojekyll` 用于直接发布静态资源。更新网站时，将重新构建的 dist 内容和更新后的源码包提交到本仓库。

园区照片和视频来自项目用户提供的素材。公开展示不自动授予素材的再利用许可。
